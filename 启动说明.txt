【快速启动方法】

方法一：直接打开（最简单）
------------------------
1. 双击打开 "index.html" 文件
2. 浏览器会自动打开登录页面
3. 使用账号登录：
   用户名：admin
   密码：123456


方法二：使用本地服务器（推荐）
--------------------------------
Mac/Linux 用户：
1. 打开终端
2. 输入以下命令：
   cd "/Users/xuexinhai/Desktop/工商储后台"
   python3 -m http.server 8080
3. 在浏览器打开：http://localhost:8080

Windows 用户：
1. 打开命令提示符(CMD)
2. 输入以下命令：
   cd "C:\Users\你的用户名\Desktop\工商储后台"
   python -m http.server 8080
3. 在浏览器打开：http://localhost:8080


方法三：使用VSCode（开发者推荐）
---------------------------------
1. 用VSCode打开项目文件夹
2. 安装 "Live Server" 扩展插件
3. 右键 index.html → "Open with Live Server"
4. 浏览器自动打开
